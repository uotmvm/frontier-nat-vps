## **端口转发是什么？怎么用？**

很多人看到"NAT VPS"三个字就有点懵，觉得没有独立 IP 不知道怎么用。这里简单解释一下。

NAT VPS 的本质是：你的服务器没有独享的公网 IPv4 地址，而是通过共享 IP + 端口映射的方式对外提供服务。AaITR 提供**免费 10 个端口转发**，登录后在管理后台配置转发规则，原理和 NPS 内外网穿透一样，操作并不复杂。

具体来说，你可以把外部某个端口映射到你的 VPS 内部某个端口，然后通过这个外部端口+IP 访问你的服务。官网提供详细的文档与转发教程，直接照着配就行。

**10 个免费端口对于大多数使用场景已经足够**，如果业务需要更多端口可以额外购买。
